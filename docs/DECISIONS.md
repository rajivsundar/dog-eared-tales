# Decisions that override docs/SRS.md

Dated 2026-10-15.

- **Build process:** one assistant (Claude Code in VS Code), step-by-step prompts. No agent crew, Antigravity, gates (G0–G5, C1, C2) or Content Factory agents.
- **Code hosting:** private GitHub repo rajivsundar/twice-told; CI is GitHub Actions. No Gitea or Gitea Actions.
- **Deployment:** Cloudflare Workers static assets via `wrangler deploy`, replacing Cloudflare Pages Direct Upload (D10, EN-1203).
- **Hosting:** production is Cloudflare Workers (static assets). Netlify is retired. GitHub Actions (`.github/workflows/deploy.yml`) runs the checks on every pull request, and on a push to `main` deploys with `cloudflare/wrangler-action` using the secrets `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`.
- **Cloudflare setup:** assets only, no Worker code (`wrangler.jsonc`: `./dist`, `not_found_handling: single-page-application`). There is no `_redirects` file (Cloudflare reads it and rejects `/*  /index.html  200` as an infinite loop; Netlify is retired). `public/.assetsignore` keeps itself out of the upload; `public/_headers` sets no-cache on `sw.js` and the manifest and long caching on `/assets/*`. `npm run deploy:dry` checks it without uploading.
- **Branching:** work on `main`, with optional pull requests; no dev/test branches yet.
- **Catalog:** a hand-picked catalog defined in `content/sources.csv`, built from unchanged Project Gutenberg EPUBs in `content/raw/` (named `pg-<number>-<book-slug>.epub`, one file per Gutenberg number). Stories inside collections, and chapters of long books, are href ranges in the original file, not split files. Both EPUB 3 (nav) and EPUB 2 (NCX) books are read. A row ships only when `content/curation.json` has a record for it with `reviewed: true`, and only the books of shipped entries are published; the other rows are built and checked but held back. `story_author` (optional) overrides the EPUB's author. The 2026-10 intake added 107 rows (from 48 more EPUBs) that wait for curation. The harvester (EN-202) and Standard Ebooks feeds are deferred.
- **Intake choices:** whole books of 17,500 words or more are not added whole; only chosen chapters are (as essays titled as printed, shown "from <book>"). Short whole books (Communist Manifesto, Tao Teh King, Apology, As a Man Thinketh, The Magic Fishbone, The Prophet) are single entries.
- **Genres:** the allowed list is horror, mystery, ghost story, satire, humour, romance, adventure, science fiction, literary, philosophy, social criticism, politics, history, memoir, spirituality, self-help, science, war and fantasy.
- **Year:** a work's `year` in curation is the year of its first appearance in print (a magazine or newspaper counts), not of a later book or revised edition.
- **Year fallback:** if a periodical date cannot be confirmed, `year` is the year of the first book collection that held the work (for example Bank Holiday and The Singing Lesson: 1922, The Garden Party).
- **Content notes:** the approved list is death, grief, violence, suicide, illness, cruelty, racism, animal harm, mental illness, sexual themes and threat to a child.
- **Hooks and blurbs:** they must not hint at a story's turn or ending: no "and then a letter" or "and then a telegram", no closing images, and no theme words that name the outcome.
- **Review policy:** each curation record has `review: "human" | "auto"`. Every record a person has read is `human` (all records shipped before batch 3). From batch 3 on, descriptions written by Claude Code are `auto`, with `reviewed: false` and `generatedBy: "claude-code"`. A record ships if it is `human` and `reviewed: true`, or `auto` and every automated check passes. An `auto` record that fails an automated check is held back, not fatal: the build goes on and lists each held-back record with its id and reason. Schema and vocabulary errors (genres, moods, content notes, year and era, form, word limits, a missing or unknown `review`) still stop the build. The automated checks are the banned-words check, the 6-word quote check and the front-matter check (below). Settings → About says: "Some descriptions are written by AI and not yet checked by a person."
- **Banned words (auto records):** hooks and blurbs may not contain, as whole words in any case: and then, twist, twists, irony, ironic, surprise, surprises, surprising, unexpected, unexpectedly, heartbreaking, jealousy, refusal, regret. The list lives in one place, `scripts/curationChecks.ts` (`BANNED_WORDS`). Closing images and theme words that name the outcome are also not allowed, but only the listed words are checked by machine.
- **Front-matter check (auto records):** an `auto` record is held back, with a reason, if its text range opens (first 1,500 characters) with Project Gutenberg front matter: "Produced by" at the start of a line, "E-text prepared by", Distributed Proofreading credits, a transcriber's or printer's note, or a foreword. The fix is to move the range's start to the story itself: in `content/sources.csv`, a single work may fill `story_href` alone (leave `story_end_href` blank) to start past front matter; it still ends at the licence and is not a collection story. The check does not apply to `human` records.
- **Reading level override:** the reading level is computed (Flesch-Kincaid) and sometimes clearly misjudges the prose: short sentences with dense vocabulary or period slang. A curation record may then set `readingLevelOverride` ("easy", "medium" or "challenging"); it must also give an `overrideReason`, one line, or the build stops; the build also stops if the override equals the computed band. Use it sparingly, only where the computed level clearly misjudges the prose. The catalog keeps the computed grade, sets the band by hand and marks it `adjusted`; the app then shows only the band (for example "Medium"), not a grade.
- **Writing descriptions:** write hooks and blurbs from the first third of the text only, and end the blurb on the situation or the question it raises, never on a theme or an outcome. Years: first appearance in print, including under an earlier title; if that cannot be confirmed, the first book collection's year, marked as unconfirmed when the record is shown. Content notes include fleeting mentions; "sexual themes" is for implied sexual content and "threat to a child" for children at risk.
- **Year basis:** a curation record may carry an optional `yearBasis` saying how its `year` was found: `"first-print"` (first appearance in print confirmed), `"collection-fallback"` (the first book collection's year, because the periodical date could not be confirmed) or `"unverified"` (not checked against a source). A fourth value, `"composition-approx"`, is for ancient works (see Ancient works). Any other value stops the build. Every `auto` record has one; older `human` records may leave it out.
- **Ancient works:** for a work written long before its first printing (The Art of War, Tao Teh King, Apology, Meditations), `year` is the approximate year of composition, with `yearBasis: "composition-approx"`. BCE years are negative whole numbers (Art of War c. -500, Tao Teh King c. -400, Apology c. -399; Meditations c. 175). The app shows them as "c. 500 BCE" or "c. 175 CE". No new era band: `pre-1800` already holds every year before 1800, negative ones included. A record may also carry `translator` and `translationYear` (the translator and year of the text we ship, from the EPUB: Lionel Giles 1910, James Legge 1891, Benjamin Jowett 1871, Meric Casaubon 1634); the detail sheet shows them on the source line, for example "Translated by Lionel Giles, 1910".
- **Curation rule:** for political, religious and philosophical texts, blurbs describe what the work argues and why it matters, without endorsing or criticising it.
- **Published images:** when the build publishes an EPUB to `public/texts`, every JPEG and PNG in it is scaled down to at most 800 px on the long edge (never enlarged) and recompressed (JPEG about quality 70; PNG stays PNG, with palette and top compression). Names, media types, page files, style sheets and the package file are kept byte for byte, so reading positions stay valid. `content/raw` is never changed. Shrunk copies are cached in `.cache/epubs` (change `SHRINK_VERSION` in `scripts/shrinkEpub.ts` when the rule changes).
- **Size rule:** after shrinking, a published EPUB over 400 KB holds back every `auto` record that uses it (the build lists each with its id and size, like other held-back records). A `human`-reviewed record over the limit is flagged in the build output (`FLAGGED`) but keeps shipping.
- **Trimming by text:** `sources.csv` has two optional columns, `startAtText` and `endBeforeText`: a piece of text where the story really starts or stops inside its first or last chapter file (spaces match any gap, line breaks included). The build and the reader both cut there. A marker that is missing or appears twice stops the build. Used for Lad: A Dog (before the transcriber's list of corrections) and The Mouse (before the printer's line).
- **Covers:** simple generated SVG covers for now; AI cover art is deferred.
- **Recommender:** tag-based scoring first; embeddings are deferred. Explain (Labs) is deferred.
- **Online data:** none in R0–R2. R3 optional sync, if built, uses client-encrypted blobs on Cloudflare R2 or KV.
- **Offline:** new story "Auto-cache Your Shortlist"; caching is Workbox precache for the shell and catalog, runtime cache-first for texts, Dexie for reader data, and OPFS for future AI models.
- **Naming:** Twice Told and the labels in CONTEXT.md; the mock-up images in `docs/` still show old labels.
- **Initial build scope:** Your Long List (simplified US-501) and the Tonight's Shortlist title (6 pm–4 am) are in the initial build.
- **Enrichment:** `content/curation.json` (year, era band, form, genres, moods, content notes, hook, blurb) is written by Claude Code in the session from each story's own text, not by a build-time LLM call. Every record is marked `generatedBy: "claude-code"` and `reviewed: false` until a person reviews it. Reading speed is 238 words per minute (EN-204). Fiction of 7,500–17,499 words is a novelette and 17,500+ a novella; non-fiction is an essay. Reading level is the Flesch-Kincaid grade of the story's own text. The archaic-word glossary is deferred.
- **Reader:** foliate-js, pinned to exactly 1.0.1 from npm, behind a `ReaderEngine` interface in `src/engine/reader/`. Only that folder may import it. Stories that sit inside a collection are shown by hiding the text outside their href range. The reading fonts (Literata, Atkinson Hyperlegible, OpenDyslexic) are packaged with the app (no font CDN). The reader screen is at /read/:id.
- **Generated files:** `public/catalog`, `public/texts` and `public/covers` are rebuilt from `content/` by `npm run catalog` (run automatically before `dev` and `build`) and are not committed.
- **Backups:** manual JSON exports (Settings → Your data); there is no sync until R3. Backup format version 2: a one-profile file (`kind: "profile"`, with the profile's name and colour) or an all-profiles file (`kind: "all"`, each profile with its colour, and which one was open). Version 1 files (before profiles) still import, as one profile. A newer version is refused. Importing a one-profile file offers "Add as a new profile" (the default) or "Replace this profile" (asks a second time); an all-profiles file replaces everything.
- **Seasonal themes:** seasonal themes are config-driven (everything lives in `src/app/seasons.ts`: dates, welcome text, the line under the Your Shortlist heading, artwork and the seasonal row), use original art only (inline SVG drawn for Twice Told; no photos, stock images or other people's art; under 30 KB in total), and switch off automatically when the season ends. The reader can also turn them off (Settings → Seasonal themes, per profile; on by default). The fall row, Tales for Longer Nights (Ghost stories for Halloween from Oct 25 to 31), holds up to 6 reviewed works that are fiction (story, novelette or novella, never an essay) and have the eerie mood or the ghost story or horror genre; "dark" counts only next to mystery or horror. It is ranked by the profile's learned weights, shows The Fall of the House of Usher first until it is finished, leaves out finished and Not for me works, shows content notes, and is stored for offline like Your Shortlist (not for the guest).
- **Reading profiles:** profiles are local to the device and are not accounts (no sign-in, no sync). Up to 6, plus a temporary guest. Every profile is for a reader aged 16 or over; the app says so on the Profiles screen and in About. A younger-reader mode stays deferred. Profiles keep reading separate; they do not lock anyone out (no PINs). Each profile has its own database (`twice-told-p-<id>`) holding its taste, events, Library, progress, highlights, settings (theme too), onboarding and daily shortlist; the registry (`twice-told-profiles`) holds the profile list, which one is open and whether storage protection was requested (one answer per device). The catalog and the saved-books cache are shared. The old single database (`twice-told`) is copied into a profile "Me", checked record by record, and deleted last; if anything fails the old data stays and the next launch tries again. "Who's reading?" (/who) shows once per browser session and after 30+ minutes away, when there are 2+ profiles. The last profile cannot be deleted (use Delete all my data). The guest starts empty, skips onboarding, does not ask for storage protection and does not save books; it survives a reload in the same tab (sessionStorage flag) and its database is deleted on switching back, or as a leftover on the next launch after the tab or app closed.
- **Known gaps:** touch text selection is blocked by the tap overlays; fix by moving taps into the page frame as a separate step, before any highlight feature ships.
- **Reader gestures:** a horizontal swipe on the page turns it (left = next, right = previous); a mostly vertical swipe does nothing, and swipes that start within 24 px of a screen edge are ignored (Android uses them for Back). The first time a profile opens the reader it sees a dismissible hint, "Tap the edges or swipe to turn pages." (`readerHintSeen` in that profile's settings); the same line is in Settings → About.
- **Dev environment:** Windows, PowerShell.
