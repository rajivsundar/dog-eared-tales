# features/onboarding

First-run onboarding at /welcome: welcome, mood board, taste cards, reading context. It shows when there is no profile and no events (`FirstRunGate`). Answers are saved as `onboard` events (a start marker, picked moods, card answers), the profile is rebuilt from the event log, and the first Your Shortlist is stored. "Redo onboarding" in Settings re-runs it without deleting history.
